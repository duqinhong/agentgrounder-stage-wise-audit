# Data availability

This repository contains code, identifier-only manifests, derived statistics, and cryptographic evidence indexes. It does **not** redistribute ScanNet point clouds, PLY/NPZ files, RGB or rendered images, ScanRefer annotations, Mask3D weights, model weights, embeddings, prompts containing restricted records, or raw model/tool logs. Obtain ScanNet, ScanRefer, and Mask3D through their official license channels, then use the identifier manifests and hashes to rebuild the audit. The 32-case package is provenance only and is not completed human annotation.
